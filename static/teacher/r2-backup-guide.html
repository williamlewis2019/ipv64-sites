服务器异地备份与恢复演练说明

2026-11-23 · R2 方案定版 · 每周备份 + 每月恢复演练

适用对象：托管 Agricalc 与 PlayVizo 的自管服务器（111.91.17.248）。 方案定版于 2026-11-23：备份到 Cloudflare R2 免费档，每月做一次恢复演练。

为什么是 R2

异地备份先后试过三个落点：

  • hubu.cloud：WebDAV 实测假写入——上传返回 201，随后下载 404、配额恒为 0。东西根本没存住，淘汰。
  • ct8.pl：2026-11-16 提交申请，官方称 24 小时开通，4 天后激活邮件仍未到，淘汰（日后若开通，可作第二备份位）。
  • Cloudflare R2：免费档 10 GB 存储、出站免费。单代备份约 267 MB，保留 4 代约 1.1 GB，完全装得下。最终选用。

备份内容（每一代的快照集）

文件 内容 约大小
agricalc-web.tar.gz /var/www/agri-tool（不含 .git） 83 MB
playvizo-web.tar.gz /var/www/playvizo（不含可再生媒体与缓存） 184 MB
playvizo-db.sql.gz MariaDB arcade 库的 mysqldump 11 MB
configs.tar.gz /etc/caddy 9 KB

运行方式

  • 脚本：服务器 /root/scripts/r2-backup.sh，凭据只在服务器 /root/.r2-backup.env（600 权限）。
  • 定时：每周日 04:15（服务器 crontab），日志 /var/log/r2-backup.log。
  • 每次上传后用远端清单逐个核对文件名与大小，全部对上才算成功；保留最新 4 代，旧代自动清理。

恢复演练（每月）

备份没验证过能恢复，等于没有备份。演练脚本 /root/scripts/restore-drill.sh，每月 1 日 05:30 自动运行，全程隔离：

  1. 从 R2 下载最新一代到隔离目录；
  2. 检查四个文件齐全；
  3. 解开两个网站包，核对文件数与首页存在；
  4. 把数据库导入临时库 restore_drill，核对表数与博客行数，随后删库；
  5. 检查配置包内含 Caddyfile；
  6. 结论写入 /root/restore-drill/result.json，并展示在 student.ipv64.de 产能看板上。

首期演练（2026-11-23）：六项全过，用时 72 秒——Agricalc 解出 1,377 个文件，PlayVizo 15,708 个，数据库 24 张表、138 篇博客。

真出事时的恢复步骤

  1. 用 rclone 把目标那一代从 R2 拉回服务器；
  2. tar -xzf agricalc-web.tar.gz -C /var/www、tar -xzf playvizo-web.tar.gz -C /var/www（注意权限：目录 755、文件 644，Caddy 才读得了）；
  3. zcat playvizo-db.sql.gz | mysql arcade 导回数据库；
  4. 从 configs.tar.gz 恢复 /etc/caddy，caddy validate 后 reload；
  5. 逐站 curl 验证 200。
