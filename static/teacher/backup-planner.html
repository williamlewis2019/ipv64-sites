Supabase Backup Planner 引流工具

2026-11-19 · 免费在线规划器 → Backup Kit 的漏斗落点

A single-page planner that estimates pg_dump size, monthly egress against the Supabase free tier's 5 GB quota, and retention storage — with the 5 traps that break naive backup setups, and a soft intro to the Supabase Free-Tier Backup Kit.

  • Pure static page: index.html (no build step, no dependencies)
  • Container: Dockerfile (nginx-unprivileged, port 8080 — orkestr runs containers as non-root)
  • LIVE: https://supabase-backup-planner.orkestr.run/ (deployed 2026-11-19, orkestr free tier, project "Supabase Backup Planner")
  • Source repo: https://github.com/williamlewis2019/supabase-backup-planner (push to main auto-deploys)
  • Funnel: Gumroad Backup Kit https://franklinlewis7.gumroad.com/l/jispyu · Free Lite repo https://github.com/liulewis/supabase-free-backup-lite
